# References

This folder contains the reference materials used to support the design of the AgriCredit Resilience project.

AgriCredit Resilience uses semi-synthetic data. The data is not copied directly from these documents. Instead, these sources helped define realistic project themes, risk factors, feature ideas, and responsible decision-support framing.

The references mainly support five areas:

1. Myanmar household vulnerability and food security

2. Rural livelihood and agriculture risks

3. Market prices and minimum expenditure needs

4. Humanitarian assistance and support targeting

5. Responsible machine learning and explainable decision support
